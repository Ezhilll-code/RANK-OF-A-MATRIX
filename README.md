# RANK-OF-A-MATRIX
## Aim:
To write a python program to find the rank of a matrix
## Equipment’s required:
1. 	Hardware – PCs
2. 	Anaconda – Python 3.7 Installation / Moodle-Code Runner
## Algorithm:
Step 1: Import NumPy and define the matrix 
𝐴


Step 2: Use np.linalg.matrix_rank(A) to compute the rank.

Step 3: Store the result in a variable (rank).

Step 4: Print the rank of the matrix.
## Program:
```
#Program to find the rank of a matrix.
#Developed by: Ezhilan H
#RegisterNumber: 212225240040

import numpy as np

A = np.array([[1, 2, 3],[3, 6, 9]])

rank = np.linalg.matrix_rank(A)

print(rank)

```
